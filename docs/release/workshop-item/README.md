# Workshop item «Cactus Info» (id 3835566412)

Копия папки `<Kenshi>/mods/Cactus Info/` (16.11.2026): пустой мод-заглушка, обложка `_Cactus Info.img`
и `_Cactus Info.info` с номером записи в Мастерской.

- Обновлять запись — только из этой папки в игре (или вернуть её отсюда, если пропала): Cactus/FCS берут
  номер из `_<имя мода>.info`, поэтому выйдет **обновление**, а не новая запись.
- Не переименовывать: `.info` и `.img` привязаны к имени мода. Новое имя = новая запись в Мастерской.
