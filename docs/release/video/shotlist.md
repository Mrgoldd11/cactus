# Список записей экрана

Все записи: 1920×1080, 30 fps (мир и полёты камеры — 60 fps), без звука (озвучка накладывается
потом), интерфейс на русском. Курсор виден (см. `recording-notes.md`). Выполнять по порядку.
Имена файлов — в `video/raw/` (папка в `.gitignore`, в репозиторий не коммитим).

Общая подготовка (один раз):

- сборка уже с логотипом Cactus и иконкой, заголовок окна «Cactus»;
- окно приложения развёрнуто на весь экран 1920×1080 (F11 / `setFullScreen`), без панели задач;
- чистые настройки пользователя (`KEDIT_USER_DATA` во временную папку) — иначе в кадр попадут
  личные недавние файлы и пути; папка игры в кадре — только в виде, заменённом на обычный путь
  Steam (как в `scripts/beta-shots.ts`, функция `hideGamePath`);
- сохранять моды только в `out/` или временную папку, **никогда** в папку игры/мастерской;
- Windows: уведомления выключены («Не беспокоить»), тёмная тема, нет посторонних окон.

## Запрос для ИИ в записи 05 (проверить заранее)

> Подключись к открытому редактору (connect_editor). Найди «Катана», сделай копию с именем
> «Катана Кактуса» и поставь урон на 20% выше ванильного. Отправь правки в окно, ничего не сохраняй.

Если формулировка даёт лишние шаги — подправить; результат не подделываем: показывается то, что
Claude реально сделал в записанном дубле.

## Чего в роликах НЕ показываем

- запись правок прямо в папку игры или мастерской;
- личные пути, имя пользователя Windows, другие окна/вкладки браузера;
- функции, которых нет: загрузка в Workshop, очистка, свои столбцы, проверка орфографии,
  поддержка ИИ кроме Claude (в озвучке — только как план).
