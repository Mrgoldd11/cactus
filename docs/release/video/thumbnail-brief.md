# Обложка YouTube — бриф

Размер 1280×720 (16:9), PNG/JPG до 2 МБ. Язык надписей — русский (ролик только русскоязычный).

## Композиция

- **Фон:** реальный скриншот интерфейса Cactus (тёмная тема) — лучше всего вид, где видно
  граф диалога или панель «Мир»; затемнить на 40–50 % и слегка размыть левую часть, чтобы
  читался текст. Скриншот — настоящий, из приложения (`docs/release/screenshots/`, берём
  1920×1080 из записи 03b или 03c), без дорисовок.
- **Логотип Cactus** — слева вверху или по центру-слева, крупно (≈ 35 % высоты кадра), на
  прозрачном фоне (версия из набора логотипов), с мягкой тенью.
- **Заголовок (2 строки, крупный жирный шрифт):**
  - «CACTUS» — название, цвет из логотипа (зелёный);
  - ниже белым: «Замена FCS для Kenshi» (≈ 48–60 pt при 1280×720).
- **Плашка-бейдж справа внизу:** «v0.1.0 BETA» на контрастной подложке.
- Справа — «вырезка» самого интересного: граф диалога с лёгким свечением (наложить скриншот
  узлов со скруглением и тенью). Лица нет — проект один человек за кадром.

## Варианты надписи (выбрать один)

1. «Замена FCS для Kenshi» — основной, прямой.
2. «Лучше FCS? Смотрим бету» — интрига, но обещание сильное: используем только если довольны.
3. «Моды Kenshi + ИИ» — акцент на Claude.
4. «FCS, но удобнее» — коротко, честно (без громких слов).

Рекомендация: вариант 1 + бейдж «BETA».

## Технические требования

- Текст не ближе 60 px к краю, высота букв ≥ 70 px (читаемость в миниатюре 168×94).
- Контраст текст/фон ≥ 4.5:1; проверить в уменьшенном виде.
- Шрифт без засечек (Inter / Montserrat Bold / аналог). Только свободные шрифты.
- Исходник слоями (PSD или SVG) + экспорт `cover-youtube-1280x720.png`.
- Не использовать ни логотип FCS, ни ассеты игры Kenshi (скриншот интерфейса редактора
  с записями из ванили допустим — это не ресурсы игры; но не добавлять арты/кадры игры).

- **Название:** «Cactus — новый редактор модов для Kenshi (замена FCS) | Бета v0.1.0»
