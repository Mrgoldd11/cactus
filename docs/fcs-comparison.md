# Cactus и официальный FCS — сравнение (2026-11-06)

Источники по FCS: `Using the FCS.pdf` из папки игры, строки из `forgotten construction set.exe`
(.NET WinForms, v2.14.2 — по ним найдены функции, которых нет в мануале), `fcs_theme.def`,
`fcs_layout.def`. Сам FCS не запускался. Про Cactus — код и ROADMAP на эту дату.

## Что у нас лучше или есть только у нас

| Область | Cactus | FCS |
| --- | --- | --- |
| ИИ | MCP-сервер (18+ инструментов), живое подключение к окну, правки ИИ — набором изменений | нет |
| Диалоги | граф с правкой мышью, проверки, проигрыватель, симулятор выбора (точное правило из exe), трассировка из игры | дерево, предпросмотр |
| «Где в игре» | цепочка обратных ссылок до города и координат | только «Show References» одним уровнем |
| Конфликты | по полям, с победителем, по всем модам из `mods.cfg` | цвет записи (оранжевый) |
| Массовые правки | предпросмотр «было → станет», одна отмена на пачку | Set Field / Find&Replace без предпросмотра |
| История | шаги понятными словами, переход к любому шагу | Undo/Redo |
| Спец-панели | матрица фракций, сравнение предметов, графы исследований/крафта/города, перепись NPC | нет |
| 3D | мир целиком, модели, «что внутри» | нет |
| Мост в игру | телепорт, камера, состояние | нет |
| Рабочее пространство | dockview, раскладки | окна MDI |
| Надёжность формата | байт в байт на 106 модах | — |
| Русские имена | везде | нет |
