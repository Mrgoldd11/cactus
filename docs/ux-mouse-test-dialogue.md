## 1. Что сделано

**Диалог в словах.** Игрок заговаривает с трактирщиком. Если в отряде игрока есть Скелет и трактирщик раньше этого собеседника не встречал, трактирщик говорит:

> «Эй, жестянка! Давно у меня не было гостей без желудка. Пиво тебе ни к чему. Чего надо?»

Игрок может ответить двумя способами:

1. «Масла бы. Суставы скрипят.» → трактирщик: «Есть масленка для вашего брата. Держи, за счёт заведения.» → **действие:** собеседник получает Ремкомплект скелета (1).
2. «Ничего. Просто прохожу мимо.» → трактирщик: «Ну и проходи. Только не греми тут.»

**Технически:**

| Что | Значение |
|---|---|
| Событие | `EV_PLAYER_TALK_TO_ME` («Игрок заговорил») |
| Кто говорит | персонаж «Трактирщик» (1187-gamedata.base), новый пакет `Barman dialogues` только для этой записи |
| Условия | `DC_MET_TARGET_BEFORE = 0` («я не встречал собеседника раньше»); раса собеседника = Скелет (target race) |
| Повтор | не чаще 48 ч (`DR_LONG_48`) |
| Бонус очков | +9 (мастер посчитал сам, чтобы обогнать диалоги, с которыми этот конкурирует) |
| Эффект | Дать вещь → Ремкомплект скелета ×1 |

**Где мод:** `D:\SteamLibrary\steamapps\common\Kenshi\mods\Dialogue Mouse Test\Dialogue Mouse Test.mod` (2859 байт). Ванильные файлы и чужие моды не трогал.

## 3. Проблемы удобства

### 🔴 Мешает сделать

Блокирующих проблем не нашёл: диалог собрался, проверился и сохранился без обхода через код.

### 🟠 Сильно путает

**О1. Пустой экран «Диалоги» не даёт создать диалог.** **[03]**
- Ожидал: на пустом экране кнопку «+ Новый диалог» или «Сделать диалог на событие…».
- Увидел: «Выберите запись типа DIALOGUE_PACKAGE, DIALOGUE, DIALOGUE_LINE, CHARACTER». Это сырые коды и никакой кнопки. Мастер нашёлся только в «Создать».
- Исправить: на пустом экране крупная кнопка «Новый диалог на событие…», которая открывает тот же мастер. Типы назвать по-русски: «пакет диалогов, диалог, реплику или персонажа».

**О2. Коды FCS видны везде по умолчанию.** **[05][11][12][13]**
- Ожидал: русский текст. Коды — по желанию.
- Увидел, среди прочего:
  - `DR_NO_LIMIT`, `DR_LONG_48`, `EV_PLAYER_TALK_TO_ME (1)`, `T_ME`, `T_TARGET`, `CE_EQUALS`, `OT_NONE`;
  - «Поле как NPC (dialogue package)», «Имя записи none»;
  - английские подсказки в «Когда можно»: «for enemies», «locked», «one at a time»;
  - кнопка «Коды FCS» включена по умолчанию.
- Исправить: «Коды FCS» выключить по умолчанию для нового пользователя. Тогда в узлах и панели остаётся только русская фраза, а код появляется по наведению. Отдельно — «(1)» после события: непонятно, что это.

**О3. Да/нет вводится числом.** **[12]**
- Ожидал: переключатель «встречал / не встречал».
- Увидел: оператор «равно · CE_EQUALS» и поле `0`. Спасает только то, что подпись сама переписывается в «я не встречал собеседника раньше».
- Исправить: для логических условий (`DC_MET_TARGET_BEFORE`, `DC_IS_IMPRISONED` и т. п.) показывать два варианта «да / нет» вместо оператора и числа.

**О4. Сломанное имя персонажа «Трактирщи/кца1/».** **[07][13]**
- Ожидал: «Трактирщик».
- Увидел: «Трактирщи/кца1/» в пикере, на узле, в «Звучит, когда» и в проигрыше. Рядом две записи «Barman», и непонятно, какая нужна.
- Исправить: найти, откуда берётся `/кца1/`. Похоже на необработанную разметку в переводе из `gamedata.po`. Для одинаковых имён показывать различие: мод-источник, фракцию, «используется в N местах».

**О5. Поиск эффектов не понимает синонимы.** **[20][21]**
- Ожидал: на «предмет» найдётся «Дать вещь».
- Увидел: «ничего не найдено». Нашлось только по «дать».
- Исправить: добавить ключевые слова к эффектам: предмет / вещь / item, деньги / cats, отношения и т. п. Если поиск пуст, показывать «Может быть: …» по ближайшим совпадениям. Та же беда у условий: «здоров» не находит группу «Здоровье и состояние».

**О6. В «Проиграть» не видно эффектов.** **[27]**
- Ожидал: после реплики трактирщика строку «→ собеседник получает Ремкомплект скелета (1)».
- Увидел: только текст реплики и «Разговор закончен». Проверить, что действие сработает, в проигрыше нельзя.
- Исправить: в проигрыше показывать эффекты реплики отдельной строкой, как в узле графа.

**О7. Панель «Проиграть» прыгает по высоте.** **[28][29]**
- Ожидал: кнопки остаются на месте.
- Увидел: после выбора ответа панель изменила высоту, мой следующий клик попал в галочку «как будто выполнено», и диалог «перестал подходить». Понять, что произошло, удалось только по кнопке «Сбросить «как будто» (1)».
- Исправить: зафиксировать высоту панели (или менять её только по перетаскиванию). Галочки «как будто» не держать прямо под местом, где только что были кнопки ответов.

**О8. Нельзя проиграть «честно» за скелета.** **[29]**
- Ожидал: режим «проверить условия по-настоящему, игрок — Скелет».
- Увидел: только «как будто выполнены (кроме закрытых)» и «только записи без условий». Проверить, что диалог не сработает для человека, нельзя.
- Исправить: режим «как в игре» с выбором расы и состава отряда игрока. Хотя бы для условий на расу, фракцию и «встречал раньше».

### 🟡 Мелочи

**М1. Счётчик пакета обнуляется.** **[08]** После выбора «Новый пакет только для этой записи» у соседней опции написано «shopkeep (есть у 0 записей)», хотя до этого было 35. Исправить: не пересчитывать счётчик от выбранного варианта.

**М2. Навигация по графу.** **[14][15]**
- Колесо мыши прокручивает, а не масштабирует. В FCS и большинстве графовых редакторов колесо — это масштаб.
- «+» приближает к центру холста, а не к выбранному узлу.
- «Показать всё» делает узлы нечитаемыми.
- После создания узел NPC обрезан правым краем.

Исправить: колесо = масштаб, Shift/Ctrl+колесо = прокрутка. Приближать к выбранному узлу. «Показать всё» ограничить снизу читаемым масштабом.

**М3. Граф сам перестраивается после клика.** **[24]** Узлы прыгают, и следующий клик приходится целить заново. Исправить: перестраивать только после добавления узла и анимированно, либо держать выбранный узел на месте.

**М4. Левая панель «Пакет» пустая после мастера.** **[13]** Мастер создал пакет `Barman dialogues`, но слева по-прежнему «Выбрать пакет…». Исправить: выбрать созданный пакет автоматически.

**М5. «Кто говорит: собеседник · T_TARGET» у реплики игрока.** **[17]** Новичок думает «говорю я, игрок». Слово «собеседник» тут взгляд NPC. Исправить: для реплик игрока писать «Игрок (собеседник NPC)».

**М6. Первым в «Часто нужных» эффектах стоит «Напасть и преследовать».** **[19]** Исправить: начинать список мирными эффектами (дать вещь, деньги, отношения, присоединиться).

**М7. Окно выбора вещи прыгает при поиске.** **[22]** Окно сжимается под результаты и переезжает в центр. Исправить: фиксированная высота окна.

**М8. «Проверить» прячет панель реплики.** **[30]** Вкладка «Реплика диалога» уходит за «∨2». Исправить: «Диагностика» открывается рядом, а не поверх.

**М9. «Как игра выбирает» не знает персонажа из проигрыша.** **[31]** Просит «выбрать персонажа (CHARACTER)», хотя в проигрыше выбран Трактирщик. Также в проигрыше «12 очков», а на узле «очки +9». Разница (+1 за условие, +2 за расу) объяснена только во вкладке справа. Исправить: передавать персонажа и показывать разбор очков прямо в строке проигрыша («9 бонус + 1 условие + 2 раса = 12»).

**М10. Не видно, где лежит мод.** **[02]** До первого сохранения путь не показан. Исправить: в шапке или строке состояния показывать «будет сохранён в Kenshi\mods\Имя\».

**М11. Объяснение бонуса очков — на жаргоне.** **[05]** «Очки», «жребий», а в соперниках у трактирщика «In cannibal cage». Полезно, но новичку тяжело. Исправить: одна фраза сверху: «Чтобы ваш диалог звучал вместо стандартного, у него должно быть больше очков. Мастер уже поставил нужное число».

## 4. Что было удобно

- **Мастер «Диалог на событие…»:** три понятных шага. Строка «Будет:» внизу заранее рассказывает результат.
- **События:** русские названия, сгруппированы. Нужное «Игрок заговорил» нашлось сразу.
- **Поиск условий и рас:** понимает русский. «скелет» и «встречал» нашлись.
- **Условия читаются фразами:** «в отряде собеседника есть Скелет», «я не встречал собеседника раньше». Подпись сама переписывается при смене значения.
- **Бонус очков** считается автоматически, с зелёно-жёлтым пояснением, кого он обгоняет.
- **Добавление реплик — лучшее место:**
  - иконка «+» на узле с понятной подсказкой;
  - панель «+ ответ игрока / + реплика NPC / + если / + →» над выбранным узлом;
  - текст вводится прямо в узле, Enter — сохранить.
  - Диалог из 6 реплик собирается за 2 минуты.
- **Эффект в узле** виден фразой: «собеседник получает Ремкомплект скелета (1)».
- **Окно выбора вещи:** английское и русское имя, мод-источник и тип в одной строке.
- **«Проиграть»:** список соперников с очками и причиной («выбран: больше всех очков», «у другого больше очков»), выбор ответов, «Вернуться к этому шагу». Это прямой ответ на вопрос «а почему мой диалог не звучит».
- **«Проверить»:** один клик, ясное «Проблем не найдено».
- **Сохранение:** само создаёт подпапку мода в `Kenshi\mods` и честно предупреждает, куда пишет.
