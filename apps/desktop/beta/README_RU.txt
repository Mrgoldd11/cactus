Kenshi Mod Editor {VERSION} — пошаговая инструкция
==================================================

Редактор модов для Kenshi: все данные игры, граф диалогов, проигрыватель разговора и помощь
нейросети (Claude). Программировать уметь не нужно.

Это бета-версия для проверки. Перед правкой своих модов делайте копию файла .mod.

Картинки к инструкции — в папке screenshots рядом с этим файлом:
  screenshots\1-start.png         — стартовый экран
  screenshots\2-katana-where.png  — катана и вкладка «Где в игре»
  screenshots\3-dialogues.png     — раскладка «Диалоги»: граф, меню, проигрыватель


ШАГ 1. РАСПАКОВАТЬ
------------------
1. Не запускайте программу прямо из архива — так она не заработает.
2. Щёлкните по архиву правой кнопкой мыши → «Извлечь все…».
3. Укажите простую папку, лучше всего C:\KenshiModEditor
   (не «Program Files» и не «Загрузки» — туда Windows иногда не даёт писать).
4. Нажмите «Извлечь». В папке будут KenshiModEditor.exe, эта инструкция, папки
   locales, resources, screenshots и служебные файлы. Ничего не удаляйте: всё нужно для работы.

Ставить Node.js, Python и прочее не нужно. Программа ничего не устанавливает в систему:
чтобы удалить её, просто удалите папку.


ШАГ 2. ПЕРВЫЙ ЗАПУСК
--------------------
1. Дважды щёлкните KenshiModEditor.exe.
2. Windows может показать синее окно «Система Windows защитила ваш компьютер».
   Это потому, что программа не подписана (подпись стоит денег, для беты её нет).
   Нажмите «Подробнее» → «Выполнить в любом случае». Это нужно только один раз.
3. Если антивирус спросит про программу — разрешите. Если он удалил файл, верните его
   из карантина или распакуйте архив заново.
4. Откроется стартовый экран (картинка screenshots\1-start.png). Вверху, в блоке
   «Папка игры», должна стоять папка Kenshi с пометкой Steam или GOG.

Ярлык на рабочий стол: правой кнопкой по KenshiModEditor.exe → «Отправить» →
«Рабочий стол (создать ярлык)».


ШАГ 3. ЕСЛИ ИГРА НЕ НАШЛАСЬ
---------------------------
Программа сама ищет Kenshi в Steam и GOG. Если вы видите «Kenshi не найдена
автоматически» или папка не та:

1. Нажмите «Выбрать папку…».
2. Укажите папку игры — ту, где лежат kenshi_x64.exe и папка data.
   Частые места:
     Steam: C:\Program Files (x86)\Steam\steamapps\common\Kenshi
            D:\SteamLibrary\steamapps\common\Kenshi   (если библиотека Steam на другом диске)
     GOG:   C:\GOG Games\Kenshi
            C:\Program Files (x86)\GOG Galaxy\Games\Kenshi
3. Как найти папку точно:
     Steam — в библиотеке правой кнопкой по Kenshi → «Управление» →
             «Просмотреть локальные файлы». Откроется нужная папка: скопируйте путь
             из адресной строки проводника.
     GOG Galaxy — откройте Kenshi → значок настроек рядом с «Играть» →
             «Управление установкой» → «Показать папку».
4. Если пишет «В папке нет data/gamedata.base» — выбрана не та папка (например,
   папка data или папка mods). Нужна папка на уровень выше.

Программа запомнит выбор. Игру она только читает; в папку игры пишет только при сохранении
мода и только после вашего подтверждения.


ШАГ 4. ПЕРВЫЕ ШАГИ В РЕДАКТОРЕ
------------------------------
Вверху справа переключатель EN / RU — язык программы.

4.1. Посмотреть игру
  1. На стартовом экране нажмите «Открыть ваниль» — это все данные игры без модов.
     Открывается за секунду-две.
  2. Слева «Категории» (оружие, персонажи, фракции…), в середине «Записи», справа «Инспектор»
     с полями выбранной записи.

4.2. Найти катану и где она в игре (картинка screenshots\2-katana-where.png)
  1. Нажмите Ctrl+F (или щёлкните поле поиска над списком записей) и наберите «катана».
     Искать можно по-русски и по-английски.
  2. Щёлкните «Катана» в списке.
  3. В инспекторе откройте вкладку «Где в игре»: у каких торговцев она продаётся, в каких
     городах, с координатами. Первый раз вкладка думает несколько секунд — читает карту мира.
     Подчёркнутые названия кликабельны: щелчок открывает ту запись.
  4. Кнопки ← → на панели — назад и вперёд по открытым записям.

4.3. Диалоги (картинка screenshots\3-dialogues.png)
  1. Меню «Окно» (вверху) → в разделе «Раскладки» выберите «Диалоги».
     Панели перестроятся: список записей, граф диалога, «Реплика», проигрыватель.
  2. В поиске наберите «Бип» и щёлкните персонажа Бип (Beep).
  3. Внизу «Проигрыватель разговора» покажет: какой диалог игра выберет, что скажет Бип
     и какие ответы увидит игрок. Нажимайте ответы — разговор пойдёт дальше.
  4. Щёлкните подчёркнутую реплику «Бип!» — диалог откроется в графе.
  5. В графе:
       - правая кнопка мыши по реплике — меню: изменить текст, добавить ответ игрока,
         добавить реплику NPC, связать, копия, удалить;
       - правая кнопка по стрелке — удалить связь или вставить реплику между;
       - двойной щелчок по реплике или F2 — правка текста прямо в узле
         (Enter — сохранить, Esc — отмена);
       - ＋ у реплики — новый ответ; протяните от правого края узла к другому — новая связь;
       - Delete — удалить выделенное, Ctrl+D — копия, колёсико мыши — масштаб;
       - подсказка по клавишам — строка внизу графа.
  6. Справа панель «Реплика» — всё о выбранной реплике: кто говорит, текст, условия,
     действия, что дальше.
  7. Вернуть обычный вид: «Окно» → «Раскладки» → «Данные».

4.4. Отмена и история
  - Кружочки ↶ ↷ на панели (или Ctrl+Z / Ctrl+Y) — отменить и повторить.
    Работает и на русской раскладке.
  - Маленькая стрелка ▾ рядом с ↶ — список последних шагов понятными словами
    («Добавлен ответ игрока „…“»). Щелчок по шагу — вернуться к нему.
  - Вся история — «Окно» → «Панели» → «История».

4.5. Свой мод: создать и сохранить
  1. Вернитесь на стартовый экран (кнопка ⌂ слева вверху).
  2. В поле «Имя файла нового мода» напишите имя латиницей, например MyFirstMod,
     и нажмите «Новый мод».
  3. Меняйте что хотите. Например: найдите катану → «Копия» → у копии поменяйте имя
     и урон. Изменённые поля подсвечиваются, а «Изменения мода» в категориях показывает
     всё, что вы поменяли.
  4. Сохраните: Ctrl+S (или кнопка «Сохранить»). Программа предложит место:
        <папка игры>\mods\MyFirstMod\MyFirstMod.mod
     Это правильное место — так мод видит лаунчер игры. Нажмите «Сохранить».
  5. Программа спросит «Запись в папку игры» → «Записать».
  6. Запустите Kenshi через лаунчер, на вкладке модов поставьте галочку у MyFirstMod.
  Другие способы:
     - «Открыть ваниль» тоже можно править: при первом сохранении программа спросит,
       куда сохранить новый мод;
     - «Сохранить как…» (Ctrl+Shift+S) — сохранить копию в другой файл;
     - открыть существующий мод: на стартовом экране в «Установленные моды» → «Открыть»,
       или «Открыть файл .mod…».
  Кнопка «Проверка» найдёт ошибки в моде (битые ссылки, пустые диалоги) до запуска игры.


ШАГ 5. ПОДКЛЮЧИТЬ НЕЙРОСЕТЬ (Claude)
------------------------------------
Нейросеть Claude может сама искать в данных игры, проходить разговоры и править мод —
а вы смотрите и принимаете или откатываете правки. Нужен Claude Desktop или Claude Code
(с учётной записью Claude). Редактор подключается к ним как «MCP-сервер».

5.1. Самый простой путь
  1. В редакторе меню «Справка» → «Подключить ИИ (MCP)…».
  2. В окне готовая настройка уже с вашим путём к программе.
     Нажмите «Копировать для Claude Desktop» или «Копировать для Claude Code».
  3. Дальше — пункт 5.2 или 5.3, только вставляйте скопированное.

5.2. Claude Desktop
  1. В Claude Desktop: «Настройки» (Settings) → «Developer» → «Edit Config».
     Откроется папка с файлом claude_desktop_config.json
     (обычно это %APPDATA%\Claude\claude_desktop_config.json). Откройте его Блокнотом.
  2. Если файл пустой или там только {} — замените всё содержимое на:

{
  "mcpServers": {
    "kenshi": {
      "command": "C:\\KenshiModEditor\\KenshiModEditor.exe",
      "args": ["C:\\KenshiModEditor\\resources\\mcp\\kenshi-mcp.mjs"],
      "env": { "ELECTRON_RUN_AS_NODE": "1" }
    }
  }
}

  3. Если вы распаковали программу не в C:\KenshiModEditor — поправьте путь в двух местах.
     Внутри кавычек каждая обратная косая черта пишется ДВАЖДЫ. Пример для папки
     D:\Games\KenshiModEditor:
        "command": "D:\\Games\\KenshiModEditor\\KenshiModEditor.exe",
        "args": ["D:\\Games\\KenshiModEditor\\resources\\mcp\\kenshi-mcp.mjs"],
  4. Если в файле уже есть "mcpServers" с другими серверами — добавьте внутрь только
     блок "kenshi": { … } и поставьте запятую между блоками.
  5. Сохраните файл и ПОЛНОСТЬЮ перезапустите Claude Desktop: закройте окно, затем
     в трее у часов правой кнопкой по значку Claude → «Выход» (Quit) и запустите снова.
  6. Проверка: «Настройки» → «Developer» — у kenshi должно быть running. В чате в меню
     инструментов (кнопка с ползунками или «+») появится kenshi.

5.3. Claude Code
  1. Откройте терминал (PowerShell) и выполните одну строку (путь — свой):

  claude mcp add kenshi --scope user -e ELECTRON_RUN_AS_NODE=1 -- "C:\KenshiModEditor\KenshiModEditor.exe" "C:\KenshiModEditor\resources\mcp\kenshi-mcp.mjs"

     Здесь косая черта одинарная — это не JSON.
  2. Проверка: claude mcp list — у kenshi должно быть Connected (✓).
     Если Claude Code был открыт — перезапустите его. Внутри Claude Code команда /mcp
     тоже показывает kenshi.

5.4. Что попросить у ИИ (просто текстом в чате)
  - «Найди катану и покажи, где она в игре».
  - «Что скажет Бип, если с ним заговорить? Пройди разговор до конца».
  - «Какие диалоги игра выберет у трактирщика и почему?»
  - «Открой мой мод MyFirstMod и проверь его на ошибки».
  - Чтобы ИИ правил то, что открыто у вас в окне редактора, сначала скажите:
    «подключись к открытому редактору». Тогда его правки придут в окно набором
    изменений (панель «Изменения ИИ», значок ✦ в истории) — вы их примете или откатите.
    Сохраняете вы сами, Ctrl+S.
  ИИ работает с той папкой игры, которая выбрана в редакторе.


ШАГ 6. ЕСЛИ ЧТО-ТО НЕ ТАК
-------------------------
Программа не запускается или сразу закрывается
  - Вы запускаете из архива — распакуйте (шаг 1).
  - Антивирус удалил или заблокировал файл — верните из карантина, добавьте папку
    в исключения или распакуйте заново.
Игра не находится — шаг 3, «Выбрать папку…».
Мод не виден в игре
  - Файл должен лежать в <папка игры>\mods\ИмяМода\ИмяМода.mod.
  - В лаунчере Kenshi на вкладке модов поставьте у него галочку.
Claude не видит kenshi
  - Полностью перезапустите Claude (через «Выход» в трее, не просто закрыть окно).
  - Проверьте путь в настройке: двойные \\ в JSON, папка та, куда вы распаковали.
  - Не забыт "env": { "ELECTRON_RUN_AS_NODE": "1" } — без него вместо сервера откроется окно
    редактора.
  - Ошибки MCP Claude Desktop пишет в %APPDATA%\Claude\logs\mcp-server-kenshi.log.
Окно пустое, зависло или ошибка
  - Пришлите журнал: «Справка» → «Открыть папку логов» → файл kenshi-mod-editor.log
    (папка %APPDATA%\Kenshi Mod Editor\logs).

Что прислать при ошибке:
  1. версию — «Справка» → «О программе» (сейчас {VERSION});
  2. файл kenshi-mod-editor.log;
  3. что вы делали перед ошибкой, по шагам, и снимок экрана (Win+Shift+S);
  4. если ошибка в моде — сам файл .mod.


ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ БЕТЫ
--------------------------
- Только Windows 10/11, 64 бита.
- Программа не подписана — отсюда предупреждение Windows.
- В диспетчере задач процесс пока называется «Electron», иконка стандартная.
- Редактор сцены (расстановка в мире) — позже; раскладка «Сцена» пока пустая.
- Установщика нет: программа живёт в папке, куда вы её распаковали.
