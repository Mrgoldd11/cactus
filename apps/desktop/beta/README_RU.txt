Kenshi Mod Editor {VERSION} — бета для проверки
================================================

Редактор модов Kenshi: данные игры, граф диалогов, проигрыватель разговора, связь с ИИ (Claude).
Это бета: сохраняйте копии своих модов.


1. ЗАПУСК
---------
- Распакуйте архив в простую папку, например C:\KenshiModEditor (не в «Program Files»).
- Запустите KenshiModEditor.exe. Node.js и прочее ставить не нужно.
- Windows может написать «Система Windows защитила ваш компьютер»: программа не подписана.
  Нажмите «Подробнее» → «Выполнить в любом случае». Антивирус тоже может спросить — разрешите.
- Игра (Steam или GOG) ищется сама. Если не нашлась — на стартовом экране «Выбрать папку…»
  и укажите папку игры (там лежат kenshi_x64.exe и папка data).
- В папку игры программа пишет только после вашего подтверждения.


2. ЧТО ПОПРОБОВАТЬ
------------------
- «Открыть ваниль» — все данные игры без мода.
- Найдите «Катана» в поиске (Ctrl+F), откройте запись, панель «Где в игре» — где этот
  предмет встречается (торговцы, отряды, города).
- Окно → раскладка «Диалоги», откройте какой-нибудь диалог: граф реплик.
  Правая кнопка мыши по реплике — меню (добавить ответ, вставить, копировать, удалить).
  Двойной щелчок или F2 — правка текста.
- ↶ ↷ на панели (Ctrl+Z / Ctrl+Y, на русской раскладке тоже) — отмена и повтор.
  Кнопка рядом — вся история шагов.
- «Проигрыватель разговора» — выберите персонажа: что он скажет и какие ответы увидит игрок.
- Сохранение — Ctrl+S. Новый мод лучше сохранять в отдельный файл (Ctrl+Shift+S).


3. ИИ ЧЕРЕЗ MCP (Claude)
------------------------
Проще всего: в программе меню «Справка» → «Подключить ИИ (MCP)…» — там готовая настройка
с правильным путём и кнопка «Копировать».

Вручную. Claude Desktop: Настройки → Developer → Edit Config, файл claude_desktop_config.json:

{
  "mcpServers": {
    "kenshi": {
      "command": "C:\\KenshiModEditor\\KenshiModEditor.exe",
      "args": ["C:\\KenshiModEditor\\resources\\mcp\\kenshi-mcp.mjs"],
      "env": { "ELECTRON_RUN_AS_NODE": "1" }
    }
  }
}

  C:\\KenshiModEditor замените на свою папку (в двух местах, с двойными \\).
  Если в файле уже есть "mcpServers", добавьте внутрь только блок "kenshi".

Claude Code (одна строка в терминале, путь — свой):

  claude mcp add kenshi --scope user -e ELECTRON_RUN_AS_NODE=1 -- "C:\KenshiModEditor\KenshiModEditor.exe" "C:\KenshiModEditor\resources\mcp\kenshi-mcp.mjs"

После настройки ПЕРЕЗАПУСТИТЕ Claude — новый MCP подхватывается только при запуске.

Что попросить у ИИ:
- «Найди катану и покажи, где она в игре».
- «Что скажет Бип, если с ним заговорить? Пройди разговор».
- «Добавь в диалог ответ игрока …» — если редактор открыт, сначала попросите
  «подключись к редактору» (connect_editor): правки придут в окно, вы их примете или откатите.


4. ЕСЛИ ЧТО-ТО СЛОМАЛОСЬ
------------------------
- Журнал ошибок: меню «Справка» → «Открыть папку логов»
  (это %APPDATA%\Kenshi Mod Editor\logs). Пришлите файл kenshi-mod-editor.log.
- Напишите, что делали перед ошибкой, и приложите снимок экрана.
- Ошибки MCP пишет сам Claude Desktop: %APPDATA%\Claude\logs\mcp-server-kenshi.log.


5. ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ БЕТЫ
-----------------------------
- Только Windows 10/11, 64 бита. Программа не подписана (предупреждение Windows — см. выше).
- В диспетчере задач процесс пока называется «Electron», иконка стандартная.
- Сцена (расстановка в мире) — позже.
- Перед правкой своих модов делайте копию файла .mod.
